# Soft (loss-based) causal-graph priors for learned world models, and how to evaluate whether a graph prior helped

Research date: 2026-11-16. Verification tags used throughout:

- **[V]** = checked this session against the linked page (abstract page, HTML full text, or proceedings entry).
- **[S]** = confirmed only from search-result snippets this session (not a full-text read).
- **[R]** = recalled from prior knowledge; the link is the paper's canonical page but was NOT re-fetched this session. Treat venue/ID as very likely right, and any detail beyond the title-level claim as needing a check before formal citation.

## 1. Jacobian-based regularizers (penalising input-output sensitivities for absent edges)

### Takeaway
Published methods fall into three mechanisms that all encode "edge j -> i absent": (a) penalise first-layer weight groups (Neural Granger), (b) penalise or mask a learned adjacency (CASTLE, mechanism sparsity, SPARTAN), and (c) penalise the actual input-output Jacobian or input gradients (Jacobian regularization, JL1-VAE, RRR). I found no published paper that applies a Jacobian penalty for a *known* absent-edge set to a pixel world model *through a probe*; that combination appears to be open.

### Cited Findings
- **Neural Granger causality** (Tank, Covert, Foti, Shojaie, Fox; IEEE TPAMI vol. 44 no. 8, 2022, pp. 4267-4279; arXiv 1802.05842). Component-wise models (cMLP, cLSTM): one network per output series. A sufficient condition for Granger non-causality of series j on series i is that all first-layer weights leaving j's lags are zero; a group-lasso penalty shrinks those groups to zero. [S] — [arXiv 1802.05842](https://arxiv.org/abs/1802.05842v2)
- **GVAR** (Marcinkevics & Vogt; ICLR 2021; arXiv 2101.07600), "Interpretable Models for Granger Causality Using Self-explaining Neural Networks". A generalised vector autoregression whose input-dependent coefficient matrices play the role of a local Jacobian; it recovers Granger-causal relations and the *signs* of effects and their variability over time; evaluated against cMLP/cLSTM. [S] — [arXiv 2101.07600](https://arxiv.org/abs/2101.07600)
- **Masked gradient-based causal structure learning** (arXiv 1910.08527, preprint as found): builds an expected absolute Jacobian and treats zero entries as missing parent relations; a sparsity term is added to the score. Static SEMs, not dynamics. [S] — [arXiv 1910.08527](https://arxiv.org/pdf/1910.08527)
- **Jacobian zero <=> no causal influence in a transition function**: a 2025 preprint on dynamic sparsity (arXiv 2511.08086) uses the Jacobian of the transition function to test sparsity assumptions, on the premise that absence of causal influence implies zero Jacobian elements. It analyses sparsity; it does not propose a Jacobian training penalty. [S] — [arXiv 2511.08086](https://arxiv.org/pdf/2511.08086)
- **Jacobian regularization, efficient computation** (Hoffman, Roberts, Yaida; arXiv 1908.02729, 2019; preprint, no venue listed on arXiv). Abstract states they "develop a computationally efficient implementation of Jacobian regularization". [V for title/authors/abstract] The mechanism, as I recall it, is a Hutchinson-style estimator: the squared Frobenius norm of the Jacobian is estimated from random unit-vector projections of the output, each costing one extra backward pass (double backprop), and a single projection per minibatch is reported as sufficient. [R — the abstract page did not state these details] — [arXiv 1908.02729](https://arxiv.org/abs/1908.02729)
- **JL1-VAE** (Rhodes & Lee; NeurIPS 2021; arXiv 2106.02923), "Local Disentanglement in Variational Auto-Encoders Using Jacobian L1 Regularization": an L1 penalty on the VAE's generative (decoder) Jacobian, motivated by ICA and sparse coding, to align latent axes with independent factors of variation. [S] — [NeurIPS proceedings](https://papers.neurips.cc/paper/2021/hash/bfd2308e9e75263970f8079115edebbd-Abstract.html); [arXiv 2106.02923](https://arxiv.org/pdf/2106.02923)
- **Mechanism sparsity regularization** (Lachapelle, Rodriguez Lopez, Sharma, Everett, Le Priol, Lacoste, Lacoste-Julien; CLeaR 2022; arXiv 2107.10098). Latents depend sparsely on past latents and/or auxiliary variables (actions); latent factors and the sparse causal graph are learned jointly; identifiability up to permutation under sparsity plus a graph-connectivity condition. Implementation is VAE-based where "the latent mechanisms are learned and regularized via binary masks". So it is a learned-mask (graph) penalty, not a soft Jacobian penalty, and it restructures the latent to be disentangled. [V] — [arXiv 2107.10098](https://arxiv.org/abs/2107.10098)
- **Sparse-Jacobian nonlinear ICA** (Zheng, Ng, Zhang; "On the Identifiability of Nonlinear ICA: Sparsity and Beyond"; NeurIPS 2022): identifiability from sparsity of the mixing function's Jacobian ("structural sparsity"). [R — search this session returned nothing for this paper] — [arXiv 2206.07751](https://arxiv.org/abs/2206.07751)
- **SPARTAN** (arXiv 2411.06890; venue not confirmed this session). Transformer world model over object tokens with *hard* attention: adjacency entries sampled A_ij ~ Bern(sigma(q_i^T k_j)) via Gumbel-softmax; path matrix over L layers defines local parents; objective E[L + lambda_s |A_bar|]. Trained with a Lagrangian relaxation: minimise E[|A_bar|] subject to E[MSE] <= tau, with tau set to the error of a fully connected model, because the model "is sensitive to the choice of lambda". [V] — [arXiv 2411.06890v3](https://arxiv.org/html/2411.06890v3)
- **Input-gradient penalty with a mask ("Right for the Right Reasons")** (Ross, Hughes, Doshi-Velez; IJCAI 2017, pp. 2662-2670; arXiv 1703.03717): explains and regularises differentiable models "by examining and selectively penalizing their input gradients"; models "generalize much better when conditions differ between training and test". This is the closest classical template for "penalise d(output)/d(input_j) for inputs the output should not depend on". [S] — [arXiv 1703.03717](https://arxiv.org/abs/1703.03717); [IJCAI PDF](https://www.ijcai.org/proceedings/2017/0371.pdf)

### Inferences
- A penalty for a known absent-edge set E_absent on an entangled-latent world model has to be defined on *named variables*, so the Jacobian in question is the composite d[probe_i(f(enc(render(s)), a))] / d s_j. Rendering is usually not differentiable, which leaves two practical routes:
  1. **Finite-difference (interventional) Jacobian**: perturb true simulator state s_j by delta, re-render, encode, predict, probe, and penalise |probe_i(pred(s + delta e_j)) - probe_i(pred(s))| for (j -> i) in E_absent (minus the direct carry-over when i = j). This reuses the existing intervention pipeline exactly and costs one extra forward pass per perturbed variable per sample. It is equivalent to the consistency losses in Section 3.
  2. **Latent-space double backprop**: use a *decoding* probe direction for variable j (or the probe's pseudo-inverse) to define a latent perturbation direction, and penalise the vector-Jacobian product w_i^T J_f v_j, where J_f is the predictor's latent Jacobian. With linear probes this needs one VJP per output variable (or Hutchinson-style random projections restricted to the absent-edge block). It is cheap but assumes the probe direction is the causal direction for s_j in latent space, which is exactly what an entangled latent does not guarantee.
- Route 1 is "model-faithful" (it only uses real interventions); route 2 inherits every weakness of the probe. This distinction matters for the circularity discussion in Section 6.
- Weight-group penalties (Tank et al.) do not transfer to a pixel encoder because pixel inputs are not grouped by causal variable; they transfer only to the state-input (privileged) version of a model.
- SPARTAN's constraint form (minimise structure penalty subject to prediction error <= dense-baseline error) is a reusable recipe for avoiding lambda tuning in any soft penalty: adapt the multiplier so prediction error never exceeds the unregularised model's.

### Gaps
- No source found that applies a Jacobian/absent-edge penalty through a trained probe on a JEPA or RSSM latent. Marked as an open design, not a published method.
- Hoffman et al.'s exact overhead figures and projection count were not verified from full text.
- GVAR's precise penalty terms (sparsity and smoothness of generalised coefficients) were not read in full text this session.
- SPARTAN's publication venue was not confirmed.

## 2. Knowledge injection of known edges into neural models

### Takeaway
Three injection styles exist: (i) embed a learned/edited adjacency in the input layer and regularise toward it (CASTLE, Russo & Toni), (ii) add edge-constraint terms to a continuous DAG-learning objective, hard or soft (NTS-NOTEARS-style hard bounds vs ECA/RoaDs soft penalties), and (iii) penalise explanations/input gradients that disagree with prior knowledge (RRR, CDEP). Style (iii) and the soft form of (ii) translate most directly to a dynamics model because they act on the function, not on the architecture.

### Cited Findings
- **CASTLE** (Kyono, Zhang, van der Schaar; NeurIPS 2020; arXiv 2009.13180), "CASTLE: Regularization via Auxiliary Causal Graph Discovery": trains a network while jointly learning the causal relationships among variables as an auxiliary task, with the learned graph embedded in the input layers; includes a generalisation bound and reports better out-of-sample performance than standard regularisers on synthetic and real data. A NeurIPS review notes scalability is an open question. [S] — [NeurIPS 2020 abstract](https://papers.neurips.cc/paper/2020/hash/1068bceb19323fe72b2b344ccf85c254-Abstract.html); [review](https://proceedings.neurips.cc/paper_files/paper/2020/file/1068bceb19323fe72b2b344ccf85c254-Review.html)
- **Russo & Toni**, "Causal Discovery and Knowledge Injection for Contestable Neural Networks" (arXiv 2205.09787): starts from CASTLE, lets experts inspect and modify the learned graph iteratively (inject known edges / forbid edges), framed as contestability. Venue and experimental results not verified this session. [S] — [arXiv 2205.09787](https://arxiv.org/pdf/2205.09787v3)
- **Soft edge-constraint integration in continuous causal discovery (ECA)** (Chen, Ban, Lyu, Sun, Hu, Wang, Chen; AISTATS 2025, PMLR 258: 3160-3168), "Continuous Structure Constraint Integration for Robust Causal Discovery": existing approaches integrate priors "in a hard way" that requires precise knowledge and performs poorly with flawed priors; the Edge Constraint Adaptive method softly represents edge presence so the prior-constraint loss is differentiable and adapts to both accurate and erroneous priors. [V, abstract level] — [ML Anthology](https://mlanthology.org/aistats/2025/chen2025aistats-continuous)
- **RoaDs** (Wang, Lin, He, Gao; arXiv 2511.06790, Nov 2025; preprint), "Robust Causal Discovery under Imperfect Structural Constraints": a surrogate model estimates data-supported weights for constrained entries (prior alignment); the knowledge term is a differentiable penalty (sigmoid instead of hard threshold, L1 only on constrained entries); data-driven and knowledge-driven objectives are treated as multi-task and combined with MGDA with gradient normalisation. The paper states that hard-constraint baselines (NTS-B) and soft-penalty baselines (ECA) "both rigidly follow flawed priors". [V] — [arXiv 2511.06790](https://arxiv.org/html/2511.06790v1)
- **RRR** (Ross et al., IJCAI 2017): see Section 1; expert annotation mask says which inputs should be irrelevant, and input gradients on those are penalised. [S] — [arXiv 1703.03717](https://arxiv.org/abs/1703.03717)
- **CDEP** (Rieger, Singh, Murdoch, Yu; ICML 2020), "Interpretations are useful: penalizing explanations to align neural networks with prior knowledge": penalises contextual-decomposition attribution scores of features that prior knowledge says should not matter; presented as an alternative to input-gradient penalties. [R — search this session did not return it] — [arXiv 1909.13584](https://arxiv.org/abs/1909.13584)
- **Informed machine learning taxonomy** (von Rueden et al.; IEEE TKDE; arXiv 1903.12394): classifies knowledge integration by knowledge source, representation (including knowledge graphs, algebraic equations, simulation results, invariances) and integration point (training data, hypothesis set/architecture, learning algorithm/loss, final hypothesis). Graph priors as a loss term fall under "learning algorithm" integration; masks fall under "hypothesis set". [R] — [arXiv 1903.12394](https://arxiv.org/abs/1903.12394)

### Inferences
- What translates to a dynamics model, in decreasing directness: RRR-style input-gradient penalties (if the model has state inputs or a differentiable path to named variables) -> soft edge-constraint penalties (if the model exposes an adjacency, e.g. attention or gating) -> CASTLE-style auxiliary graph discovery (requires a variable-factored input layer, so it applies to state-input models or to a probe-space auxiliary model, not directly to a pixel encoder).
- For an entangled pixel latent, a practical analogue of CASTLE is an auxiliary *probe-space transition head* g: probe(z_t), a_t -> probe(z_{t+1}) constrained/regularised to the expert graph and trained jointly, so that gradients shape z without changing its architecture. This is my construction, not something a source reports.
- Monotonicity/sign constraints fit naturally with GVAR-style signed effects: the expert graph can carry signs (e.g. force -> cart acceleration positive) and a hinge penalty on the sign of finite-difference responses would be the soft version.

### Gaps
- I did not verify a specific paper on monotonicity constraints for dynamics models; no source cited.
- Did not verify the original NOTEARS-with-prior-knowledge formulations (e.g. NTS-NOTEARS) from their own pages; only via RoaDs' description of baselines.
- Russo & Toni venue (I believe ECAI 2023) unverified.

## 3. Interventional / counterfactual consistency losses

### Takeaway
The best-established way to make a model "ignore non-parents" without masks is to train on counterfactual pairs: swap or perturb the non-parent factors and require the prediction for the target factor to be unchanged. CoDA/MoCoDA/CAIAC do this as data augmentation in factored state space; Veitch et al. and block-MDP ICP give the regulariser view; DrQ/CURL/SODA are the pixel-space special case where the "non-parent" is a nuisance image transform.

### Cited Findings
- **CoDA** (Pitis, Creager, Garg; arXiv 2007.02863; NeurIPS 2020 per assignment brief, venue not re-confirmed): counterfactual data augmentation using locally factored dynamics; swaps locally independent sub-components between observed transitions; "significantly improves the performance of RL agents in locally factored tasks, including the batch-constrained and goal-conditioned settings". [S] — [arXiv 2007.02863](https://arxiv.org/abs/2007.02863)
- **MoCoDA** (Pitis, Creager, Mandlekar, Garg; NeurIPS 2022; arXiv 2210.11287): generalises CoDA; three steps: build a parent distribution, apply a learned (locally factored) dynamics model to generate augmented transitions, train an off-policy agent. Project page reports ~40% success with unprioritised MoCoDA versus <5% without on an OOD task. [S] — [arXiv 2210.11287](https://arxiv.org/pdf/2210.11287); [project page](https://sites.google.com/view/mocoda-neurips-22)
- **CAIAC** (Armengol Urpi, Bagatella, Vlastelica, Martius; ICML 2024, PMLR 235: 1709-1729; arXiv 2405.18917): uses causal action influence (state-conditioned mutual information) to identify entities the action does not affect, then creates counterfactual transitions by swapping those entities' states between trajectories in the offline dataset; reduces causal confusion and improves robustness to test-time distribution shift. Code pipeline: train a world model, then train the downstream algorithm on augmented data. [S] — [arXiv 2405.18917](https://arxiv.org/html/2405.18917v2); [code](https://github.com/martius-lab/caiac)
- **Counterfactual invariance** (Veitch, D'Amour, Yadlowsky, Eisenstein; NeurIPS 2021 spotlight; arXiv 2106.00545): provides "practical schemes for learning (approximately) counterfactual invariant predictors (without access to counterfactual examples)"; "Distinct causal structures require distinct regularization schemes to induce counterfactual invariance", depending on whether the label causes the features or vice versa. [V, abstract] The regularisers, as I recall, are MMD penalties enforcing a (conditional) independence between the predictor and the nuisance variable, with conditioning on the label in the anti-causal case. [R] — [arXiv 2106.00545](https://arxiv.org/abs/2106.00545)
- **Invariant Causal Prediction for Block MDPs** (Zhang, Lyle, Sodhani, Filos, Kwiatkowska, Pineau, Gal, Precup; ICML 2020): uses multiple training environments and an invariance objective (IRM/ICP-style, with an adversarial environment classifier in the rich-observation case) to learn a state abstraction containing only the causal parents of reward/next state, giving generalisation to unseen environments. [R — search this session did not return it] — [arXiv 2003.06016](https://arxiv.org/abs/2003.06016)
- **Augmentation-consistency in pixel RL**: DrQ (Kostrikov, Yarats, Fergus; ICLR 2021) averages Q targets/predictions over random shifts; CURL (Laskin, Srinivas, Abbeel; ICML 2020) uses a contrastive loss between augmented views; SODA (Hansen & Wang; ICRA 2021) adds an auxiliary latent-consistency loss between strongly augmented and clean views. [R] — [DrQ arXiv 2004.13649](https://arxiv.org/abs/2004.13649); [CURL arXiv 2004.04136](https://arxiv.org/abs/2004.04136); [SODA arXiv 2011.13389](https://arxiv.org/abs/2011.13389)
- **Soft-mask + counterfactual consistency in a non-RL model**: CausalAffect (arXiv 2512.00456) uses a sigmoid soft mask over graph edges together with counterfactual consistency and discrepancy losses that reinforce informative edges and suppress spurious ones. [S] — [arXiv 2512.00456](https://arxiv.org/pdf/2512.00456)

### Inferences
- With a simulator that can set true states and re-render, the CoDA construction becomes an exact *consistency loss* for a pixel world model: for each edge (j -> i) absent in the expert graph, sample s, form s' = s with s_j resampled (holding everything else fixed), and penalise || h_i(pred(enc(render(s)), a)) - h_i(pred(enc(render(s')), a)) ||, where h_i is a readout of next-step variable i. Present edges can get the complementary "discrepancy" term (response should be non-zero / match the simulator's delta). This is the finite-difference Jacobian penalty of Section 1 with large, on-distribution perturbations.
- Causal reading of DrQ/CURL/SODA: the augmentation is an intervention on a variable known a priori to have no edges into task variables. The expert-graph version just makes the invariance target-specific (invariance of variable i to variable j) instead of global.
- A probe-free variant exists and avoids circularity: require the *latent* predictions for s and s' to differ only by what the *encoder* difference explains, e.g. match pred(enc(render(s'))) - pred(enc(render(s))) to enc(render(sim(s'))) - enc(render(sim(s))) (the target-encoder shift). That uses the simulator as teacher in embedding space and needs no probe; it is what the NeurIPS 2026 JEPA paper in Section 6 measures as an evaluation.
- One-step invariance to non-parents is only valid at the simulator step at which the graph is defined; with frame-skip or multi-step prediction, the correct absent-edge set is that of the k-step (transitively closed) graph.

### Gaps
- No source found that uses CoDA-style pairs as an explicit invariance *loss* on a JEPA/RSSM pixel world model with a known graph; published uses are data augmentation for policy learning in factored state space.
- Veitch et al.'s and Zhang et al.'s exact loss forms not verified from full text this session.

## 4. Distilling a known SCM / simulator structure into a world model

### Takeaway
Besides penalties, structure can be injected by supervision (auxiliary heads / weak physical labels), by making part of the latent dynamics obey a physical form (Hamiltonian, port-Hamiltonian, PDE branch), or by replacing the latent model with differentiable physics. Recent (2024-2026) "physically grounded" world models mostly restructure the latent or add a structured branch, i.e. they are not purely soft.

### Cited Findings
- **Physically Interpretable World Models (PIWM)** (Mao, Umasudhan, Ruchkin; arXiv 2412.12870, v6 Apr 2026; preprint): aligns latents with physical quantities using "weak distribution-based supervision" (no exact ground-truth state labels), with a VQ-based visual encoder, a transformer-based physical encoder and a learnable dynamics model built on known physical equations; case studies on **Cart Pole**, Lunar Lander and Donkey Car; claims accurate long-horizon prediction and recovery of true system parameters. [V, abstract] — [arXiv 2412.12870](https://arxiv.org/abs/2412.12870)
- **PH-Dreamer** (arXiv 2605.18303, May 2026; preprint): a Port-Hamiltonian RSSM that incorporates implicit physical priors by *regularising projected latent dynamics* in a structured phase space, plus an energy world model estimating the Hamiltonian and power balance from proprioception; motivated by standard RSSMs being "physically unstructured". [S] — [arXiv 2605.18303](https://arxiv.org/pdf/2605.18303.pdf)
- **DynaDreamer** (arXiv 2607.13410, 2026; preprint): Dreamer-style driving model with an explicit ego-dynamics prior and physics-informed ego-dynamics encoder-decoder. [S] — [arXiv 2607.13410](https://arxiv.org/abs/2607.13410)
- **PIN-WM** (Li, Zhao, Yu, Du, Zou, Hu, Xu; arXiv 2504.16693, Apr 2025): identifies 3D rigid-body dynamics end-to-end from images with differentiable physics and a Gaussian-splatting rendering loss, from few-shot task-agnostic interaction trajectories; an environment-specific physics model, not a latent Dreamer-style model. [S] — [arXiv 2504.16693](https://arxiv.org/html/2504.16693v2)
- **CausalVAE as a plug-in for world models** (Ding, Lai, Chen, Zhang, Chen; arXiv 2604.07712, Apr 2026; preprint): a causal structural module added to several encoder-transition backbones; factual prediction stays competitive while intervention-aware counterfactual retrieval improves; on the Physics benchmark CF-H@1 improves ~102.5% on average across 8 paired baselines (e.g. GNN-NLL 11.0 -> 41.0); learned structure recovers first-order physical interaction trends. [V, abstract] — [arXiv 2604.07712](https://arxiv.org/abs/2604.07712)
- **Classical structured-dynamics priors**: PhyDNet (Le Guen & Thome; CVPR 2020) splits the latent into a PDE-constrained physical branch and a residual branch; Hamiltonian Neural Networks (Greydanus, Dzamba, Yosinski; NeurIPS 2019) and Lagrangian Neural Networks (Cranmer et al., 2020, ICLR workshop) parameterise the dynamics via an energy function. [R] — [PhyDNet arXiv 2003.01460](https://arxiv.org/abs/2003.01460); [HNN arXiv 1906.01563](https://arxiv.org/abs/1906.01563); [LNN arXiv 2003.04630](https://arxiv.org/abs/2003.04630)
- **Privileged structure as a mask in a learned world model** (Ghosh; arXiv 2607.26336, Jul 2026; technical report): PCMCI+ skeleton turned into a tensor mask C applied by Hadamard product, s_hat_{t+1} = Phi(x_t ⊙ C; theta); baselines other than the graph-free AWM receive a "differentiable soft PCMCI mask that weights inputs by link significance". [V] — [alphaXiv 2607.26336](https://www.alphaxiv.org/abs/2607.26336.md)

### Inferences
- The cheapest "distillation" for an existing JEPA/Dreamer is an auxiliary supervised head predicting ground-truth next-state deltas (privileged information available in simulation). It shapes the latent without masks, but it gives *state information*, not *graph structure*: a dense head can predict deltas correctly in-distribution while still using non-parents. To inject the graph, the head (not the latent) can be hard-masked to the expert parent sets, or teacher-SCM counterfactual rollouts (targets under interventions, Section 3) can be added.
- Teacher-SCM targets under intervention are the supervised dual of the invariance loss: instead of "response to non-parent = 0" for absent edges only, the model is given the full interventional response vector for every variable.
- The 2024-2026 physics-informed world models found here all add a structured branch or structured latent (PIWM, PH-Dreamer, DynaDreamer, PhyDNet) rather than leaving an entangled latent untouched; PH-Dreamer's "regularising projected latent dynamics" is the closest to a soft, projection-based (probe-like) prior.

### Gaps
- No paper found under the exact name "physics-informed Dreamer"; PH-Dreamer and DynaDreamer are the nearest matches. Full texts of PH-Dreamer, DynaDreamer, PIWM not read (losses and metrics unverified).
- No verified source on privileged-information (LUPI-style) training specifically for world models was retrieved this session.

## 5. Hard vs soft priors, and robustness to a partly wrong graph

### Takeaway
Direct, controlled hard-mask-versus-soft-penalty comparisons under graph misspecification in a *world-model* setting were not found. The available evidence: in causal discovery, soft integration is argued and shown to be more tolerant of wrong priors (ECA, RoaDs, with a standard corruption protocol); in world models, one 2026 technical report finds a corrupted hard mask is worse than no mask; and SPARTAN argues hard attention is needed for clean structure.

### Cited Findings
- **Corrupted hard mask worse than dense baseline** (Ghosh, arXiv 2607.26336, technical report, not peer-reviewed): corrupting the causal mask inflates prediction error in all six environment groups, with median inflation from 1.16x (not significant) to 17.9x, growing as the corruption level approaches 1; the paper states a corrupted graph is worse than no graph. Where the graph helps: under partial observation on a stretched two-door layout, the masked model reaches 0.53x the graph-free model's error; under full matched data a graph-free model matches the masked model. Statistics: 50 paired runs (Fig. 4B), 10 runs per point (Fig. 4C), Wilcoxon and Mann-Whitney tests. [V] — [alphaXiv 2607.26336](https://www.alphaxiv.org/abs/2607.26336.md)
- **Soft integration adapts to erroneous priors** (ECA, AISTATS 2025): hard integration "requires precise information" and struggles with erroneous priors; soft, differentiable edge-presence representation is more flexible for accurate and erroneous priors. [V, abstract] — [ML Anthology](https://mlanthology.org/aistats/2025/chen2025aistats-continuous)
- **Even soft penalties can follow a flawed prior** (RoaDs, arXiv 2511.06790, preprint): claims both hard (NTS-B) and soft (ECA) baselines rigidly follow flawed priors; as the flawed-constraint fraction p_b rises, ECA's SHD rises sharply while RoaDs stays low. Numbers at the default setting — linear Gauss ER-2: RoaDs F1 0.821 / SHD 11.4, GOLEM-EV 0.807 / 12.1, NTS-B 0.787 / 13.2, ECA 0.661 / 24.0; nonlinear MLP ER-2: RoaDs 0.578 / 25.9, NOTEARS-MLP 0.489 / 31.9, ECA 0.344 / 107.4. [V] — [arXiv 2511.06790](https://arxiv.org/html/2511.06790v1)
- **Reusable prior-corruption protocol** (RoaDs): sample p_a·k·n_v true edges as positive constraints; sample p_c·p_a·k·n_v non-edges as negative constraints; flip a fraction p_b of the constraints; defaults n_v = 20, k = 2, p_a = p_b = 0.3, p_c = 1; ten repetitions. [V] — [arXiv 2511.06790](https://arxiv.org/html/2511.06790v1)
- **Case for hard structure** (SPARTAN): sparsity regularisation with hard attention gives much lower SHD than a soft-attention Transformer whose attention is thresholded post hoc (Pong SHD 1.51 vs 6.37; CREATE 1.17 vs 6.29; Traffic 6.84 vs 10.6), with the Transformer's threshold chosen for best SHD, which the authors note "is not possible in practice"; prediction error is comparable (Pong 8.60 vs 8.83; Traffic 0.52 vs 0.51). [V] — [arXiv 2411.06790v3](https://arxiv.org/html/2411.06890v3)
- **Graduated / confidence-weighted priors**: Ghosh's baselines use a soft PCMCI mask that "weights inputs by link significance" [V] — [alphaXiv 2607.26336](https://www.alphaxiv.org/abs/2607.26336.md); CDFM (arXiv 2607.11508, 2026 preprint) uses a soft differentiable causal mask whose edge weights can be refined at inference by minimising reconstruction error [S] — [arXiv 2607.11508](https://arxiv.org/pdf/2607.11508); RoaDs' prior alignment down-weights prior edges the data do not support [V] — [arXiv 2511.06790](https://arxiv.org/html/2511.06790v1).

### Inferences
- The asymmetry of errors is predictable: a wrongly *absent* edge under a hard mask removes information the model needs (unbounded error, as in the 17.9x case), whereas under a soft penalty the prediction loss can pay the penalty and keep the edge; a wrongly *present* edge costs little under either. So wrong-graph ablations should report "missing true edge" and "extra false edge" corruptions separately.
- A three-class expert graph (strong / weak / absent) maps naturally to per-edge penalty weights lambda_ij (large for confidently absent, small or zero for weak, none or a discrepancy term for strong), or to per-edge prior probabilities used as weights as in the significance-weighted PCMCI mask.
- MGDA-style or constraint-style balancing (RoaDs; SPARTAN's Lagrangian) is the published answer to "soft penalty still drags the model toward a wrong prior": bound the prediction-loss degradation instead of fixing lambda.
- A hard-vs-soft-vs-dense comparison under the RoaDs corruption protocol, in a pixel world model, appears to be a real gap in the literature and therefore a contribution opportunity.

### Gaps
- No controlled hard-mask vs soft-penalty comparison under misspecification for world models found (the search tool's own summary reached the same conclusion).
- Ghosh 2607.26336: Appendix V (exact definition of ground-truth / discovered / corrupted / dense masks) was not in the portion read; the report is single-author and unreviewed.
- ECA's quantitative results not read in full text.
- No verified source on Bayesian edge-wise prior probabilities in world models specifically.

## 6. Evaluation methodology: how papers show a causal prior helped

### Takeaway
The recurring evidence types are: (1) prediction error at matched data plus structure agreement (SHD/F1), (2) robustness to removing or perturbing non-causal entities, (3) few-shot adaptation to interventions, (4) OOD return / generalisation gap with an oracle and a standard baseline, (5) counterfactual retrieval or paired-intervention accuracy, and (6) wrong-graph and dense-baseline controls with paired statistical tests. Probe circularity is rarely addressed explicitly; the nearest published guidance is control tasks/selectivity (Hewitt & Liang) and stage-by-stage intervention tracing with a matched control (NeurIPS 2026 JEPA paper).

### Cited Findings
**Metrics and protocols in graph-informed world-model papers**
- SPARTAN reports (a) one-step prediction error, (b) SHD of the learned local graph against ground truth, (c) *robustness* = mean absolute percentage change in prediction error when non-causal entities are removed (SPARTAN 24.5 ± 4.4 Pong, 28.6 ± 1.7 CREATE, 13.9 ± 0.2 Traffic vs Transformer 1140.2 ± 15, 138.2 ± 5.6, 32.8 ± 0.4), and (d) few-shot adaptation from 5 trajectories to seen and unseen interventions. Baselines: dense Transformer and a global (non-local) graph model. Seed counts are not stated for the main tables. [V] — [arXiv 2411.06890v3](https://arxiv.org/html/2411.06890v3)
- Ghosh (2607.26336) reports normalised prediction error (next-state MSE / next-state variance), graph error as normalised spectral distance between discovered and ground-truth graphs, mask-corruption dose-response curves, a graph-free baseline (AWM), and Wilcoxon / Mann-Whitney tests over 50 paired runs. Key qualitative result: the graph helps under partial observation / limited coverage but not under full matched data. [V] — [alphaXiv 2607.26336](https://www.alphaxiv.org/abs/2607.26336.md)
- CausalVAE plug-in (2604.07712) evaluates factual prediction plus counterfactual retrieval (CF-H@1, hits-at-1 of the correct counterfactual outcome) across 8 paired with/without-module backbones. [V, abstract] — [arXiv 2604.07712](https://arxiv.org/abs/2604.07712)
- Causal RL survey experiments (da Costa Cunha, Liu, French, Mian; arXiv 2512.18135, Dec 2025; preprint): metrics are in-distribution vs OOD return, generalisation gap and "gap reduction (%)" (Study A), gap closed relative to an Oracle baseline (Study B), OPE MAE and correlation (Study C), transfer gain (Study D), explanation variance and dynamics correlation/R^2 (Study E). Reports mean with 95% confidence intervals over "3-5 random seeds"; no formal significance test named. Standard baselines: a Standard agent with all features, a Causal agent with only core features, and an Oracle that sees the true confounder. [V] — [arXiv 2512.18135](https://arxiv.org/html/2512.18135)
- CAIAC / CoDA / MoCoDA evaluate by downstream policy success/return under test-time distribution shift (e.g. MoCoDA ~40% vs <5% success). [S] — [MoCoDA project page](https://sites.google.com/view/mocoda-neurips-22); [CAIAC arXiv 2405.18917](https://arxiv.org/html/2405.18917v2)
- CSML's CausalWorld-style 2D physics benchmark (arXiv 2509.12387, 2025 preprint) splits questions into predictive, interventional and counterfactual categories; correlational models do well on prediction but fail on interventional/counterfactual. [S] — [arXiv 2509.12387](https://arxiv.org/pdf/2509.12387)
- What-If World (arXiv 2605.27589, May 2026 preprint): contrastive-intervention (paired) benchmark for video world models in driving and manipulation; best model about 51.7% on the paired metric, open-source models near 28%. [S] — [arXiv 2605.27589](https://arxiv.org/html/2605.27589)

**Structure-agreement metrics**
- SHD and F1 against the true graph are the standard structure metrics (RoaDs; SPARTAN uses SHD). [V] — [arXiv 2511.06790](https://arxiv.org/html/2511.06790v1); [arXiv 2411.06890v3](https://arxiv.org/html/2411.06890v3)
- Caveat documented by SPARTAN: SHD of a dense model depends on a post hoc threshold; choosing the threshold for best SHD is an oracle choice. [V] — [arXiv 2411.06890v3](https://arxiv.org/html/2411.06890v3)

**Statistical practice**
- rliable (Agarwal, Schwarzer, Castro, Courville, Bellemare; NeurIPS 2021, "Deep Reinforcement Learning at the Edge of the Statistical Precipice"): recommends interquartile mean (IQM), stratified-bootstrap confidence intervals, performance profiles and probability of improvement instead of point estimates over few seeds. [R] — [arXiv 2108.13264](https://arxiv.org/abs/2108.13264)
- Paired non-parametric tests (Wilcoxon signed-rank on paired runs, Mann-Whitney on unpaired) are used in the mask-corruption study. [V] — [alphaXiv 2607.26336](https://www.alphaxiv.org/abs/2607.26336.md)

**Probe validity and circularity**
- Control tasks and selectivity (Hewitt & Liang; EMNLP-IJCNLP 2019; arXiv 1909.03368): a good probe should be *selective* — high accuracy on the real task and low accuracy on a control task (labels a probe can only memorise); selectivity is the gap. MLP probes at popular settings have very low selectivity; linear probes are more selective (e.g. POS tagging 97.2 accuracy, 71.2 control accuracy, 26.0 selectivity); dropout does not improve MLP selectivity but other regularisation does. [S] — [arXiv 1909.03368](https://arxiv.org/abs/1909.03368)
- Stage-by-stage intervention tracing for JEPA world models (Subramanian; NeurIPS 2026 listing, "Counterfactual Action Evaluation, Observation Bottlenecks, and Representation Geometry in Joint-Embedding Predictive World Models"): argues low latent prediction error does not show a model distinguishes consequences of its actions; the protocol "traces the same intervention through simulator state, raster observations, target embeddings, and predictor outputs": (1) exact simulator-state forks differing only in the action, (2) check the change is visible in raster observations, (3) compare the predictor's response with the target-embedding shift, with and without variance normalisation, (4) a matched control — an isotropic state perturbation matched in size to the counterfactual embedding shift — to separate action-path under-use from a dead or globally shrunk predictor. This protocol is probe-free. [V, listing page; full paper not read] — [NeurIPS 2026 virtual listing](https://neurips.cc/virtual/2026/165869)

### Inferences
**Recommended control set (synthesised from the above; each control is used in at least one cited paper unless marked "mine")**
- Dense baseline with identical architecture/parameters and lambda = 0 (SPARTAN's Transformer; Ghosh's AWM; survey's StandardPPO).
- Oracle/upper bound (survey's Oracle PPO; a state-input masked model here).
- Wrong-graph dose-response: corrupt the prior at increasing rates (Ghosh; RoaDs protocol with p_b), separately for deleted true edges and added false edges (separation is mine).
- Shuffled / random graph with matched edge count (mine as a named control; it is the limit of the corruption curve). This distinguishes "the right graph helps" from "any sparsity regulariser helps".
- Matched-magnitude generic regulariser (e.g. unstructured Jacobian Frobenius penalty per Hoffman et al., at the same penalty strength) to separate graph-specific benefit from smoothness (mine).
- Data-regime sweep: the one world-model study that looked found the graph helps under partial observation / limited data and not under full matched data, so sample-efficiency curves at several dataset sizes are the place an effect is expected.
- Statistics: paired seeds across conditions with Wilcoxon signed-rank (Ghosh), or IQM + stratified bootstrap CIs (rliable); 3-5 seeds with CIs (survey) is the weak end of current practice.

**Circularity risk when the probe is in both the loss and the metric**
- If the penalty is "probe_i(prediction) must not move when s_j is intervened", the model can satisfy it by making the *probe's readout direction* insensitive while still carrying and using s_j elsewhere in the latent (the predictor routes the dependence into a subspace the probe ignores). A same-probe evaluation would then report perfect graph agreement. No source I found discusses this exact failure for world models; the following mitigations are adapted from the probing literature and the NeurIPS 2026 protocol:
  1. **Fresh probes after training**: freeze the regularised model, train new probes from scratch (different seed, different data split, and ideally a different probe class, e.g. train with linear, evaluate with small MLP and vice versa) and report recovered-graph metrics with those.
  2. **Probe-free metric**: compare predictor response to the target-encoder embedding shift under the same simulator intervention (Subramanian's protocol), including the matched isotropic control.
  3. **Selectivity / control tasks**: report probe accuracy on a control variable (e.g. shuffled labels or a random function of state) alongside real-variable accuracy (Hewitt & Liang) so that probe capacity is not mistaken for structure.
  4. **Held-out interventions**: evaluate on intervention magnitudes, variables-pairs or state regions not used in the consistency loss (e.g. train on small perturbations of a subset of absent edges, test on larger ones and on the remaining absent edges), mirroring SPARTAN's seen/unseen-intervention split.
  5. **Downstream, probe-independent outcomes**: multi-step rollout error in pixel/embedding space, OOD physics generalisation, distractor robustness and control return do not use the probe at all, so improvements there cannot be a probe artefact.
- Recovered-graph metrics need a threshold-free form (AUROC / AUPRC over edge scores) or a threshold fixed by a null calibration, since SPARTAN documents that post hoc thresholds can be oracle-tuned.

### Gaps
- No published guidance found that addresses probe-in-loss/probe-in-metric circularity for world models specifically; the mitigations above are adaptations.
- Subramanian's paper was read only at the listing level; quantitative findings and venue track (main/workshop) unverified.
- rliable recommendations cited from memory, not re-read.
- No verified example of a paper reporting AUROC of recovered graphs for a regularised pixel world model.
- Multi-step rollout error as evidence for graph priors: not verified from a specific source this session (SPARTAN's reported errors are prediction errors; horizon not confirmed).

## 7. Benchmarks suited to the question

### Takeaway
For a pixel world model with a known simulator graph, the most relevant established benchmarks are CausalWorld, CoPhy, CLEVRER, CausalCircuit, Distracting Control Suite and CARL; the Dec 2025 survey's eleven environments are lightweight confounding/spurious-feature tasks (including CartPole physics variants) and are closest to a cart-pole study but are state-based.

### Cited Findings
- **Causal RL survey environments** (arXiv 2512.18135, Dec 2025, preprint; 26 pages, 14 figures, 5 algorithms). Eleven environments across studies: three CartPole physics variants built with a SpuriousFeatureWrapper (Standard: pole length 0.5, mass 0.1; LongPole: length 1.0; HeavyPole: mass 0.3); ConfoundedBandit, BanditHard, ConfoundedFrozenLake, ConfoundedBlackjack; ConfoundedDosage, ConfoundedPricing, ConfoundedTargeting; and a VisualDistractionWrapper (levels 0-5: colour jitter, background patterns, camera shake; applied to CarRacing at level 5 and Pendulum at level 1). The suite is described as isolating "confounded observations, spurious correlations, distribution shift, and hidden common causes". SpuriousFeatureWrapper adds 8 spurious features to CartPole-v1's 4 core features; in training they correlate with the optimal action (shortcut strength 5.0, 4 training domains), at test they are pure noise. Reported headline: CausalPPO closes 99.8-100% of the generalisation gap vs StandardPPO. [V; note the exact grouping into eleven was reconstructed by the fetch tool from Section II-D and should be checked against the paper's own table] — [arXiv 2512.18135](https://arxiv.org/html/2512.18135)
- **Interventional Pong, CREATE, Traffic** (used by SPARTAN): object-token environments with ground-truth local causal graphs and interventions, supporting SHD, non-causal-entity-removal robustness and few-shot intervention adaptation. [V] — [arXiv 2411.06890v3](https://arxiv.org/html/2411.06890v3)
- **CausalWorld** (Ahmed, Trauble, et al.; ICLR 2021): robotic manipulation (TriFinger) benchmark for causal structure and transfer learning, with do-interventions on environment variables (masses, sizes, colours, friction, goals) and defined train/eval intervention spaces for generalisation protocols. [R] — [arXiv 2010.04296](https://arxiv.org/abs/2010.04296)
- **CoPhy** (Baradel, Neverova, Mille, Mori, Wolf; ICLR 2020): counterfactual learning of physical dynamics from video — observe a sequence, apply an intervention to the initial state, predict the counterfactual outcome, with unobserved confounders such as mass and friction. [R] — [arXiv 1909.12000](https://arxiv.org/abs/1909.12000)
- **CLEVRER** (Yi, Gan, et al.; ICLR 2020): collision-event videos with descriptive, explanatory, predictive and counterfactual questions. [R] — [arXiv 1910.01442](https://arxiv.org/abs/1910.01442)
- **CausalCircuit** (introduced in Brehmer, de Haan, Lippe, Cohen; "Weakly supervised causal representation learning"; NeurIPS 2022): rendered robot-arm-and-lights scene with a known causal graph between latent variables and paired pre/post-intervention images. [R] — [arXiv 2203.16437](https://arxiv.org/abs/2203.16437)
- **Distracting Control Suite** (Stone et al., 2021; preprint): DM Control with background-video, colour and camera distractions at graded difficulty. [R] — [arXiv 2101.02722](https://arxiv.org/abs/2101.02722)
- **CARL** (Benjamins et al.; TMLR 2023): contextual-MDP extensions of standard environments (incl. classic control and DMC) with configurable physics contexts (gravity, masses, lengths) for train/test context generalisation. [R] — [arXiv 2110.02102](https://arxiv.org/abs/2110.02102)
- **Cart Pole as a physically-interpretable world-model testbed**: PIWM (arXiv 2412.12870) uses Cart Pole, Lunar Lander and Donkey Car. [V] — [arXiv 2412.12870](https://arxiv.org/abs/2412.12870)
- **What-If World** (arXiv 2605.27589, 2026 preprint): paired contrastive-intervention benchmark for general video world models. [S] — [arXiv 2605.27589](https://arxiv.org/html/2605.27589)

### Inferences
- Mapping benchmarks to evidence types: CARL / the survey's LongPole-HeavyPole variants -> held-out-physics generalisation; Distracting Control Suite / VisualDistractionWrapper / SpuriousFeatureWrapper -> distractor and spurious-correlation robustness; CoPhy / CLEVRER / CausalCircuit / What-If World -> counterfactual and paired-intervention prediction; CausalWorld / Interventional Pong -> intervention-space generalisation and few-shot adaptation.
- The survey's CartPole variants (2x pole length, 3x pole mass, 8 spurious features turning to noise at test) are directly reproducible on an existing cart-pole pipeline and give a published reference protocol for OOD-physics and spurious-feature tests, although the survey's agents are state-based PPO, not pixel world models.
- An existing in-house distractor variable (a rendered object with no causal edges into physical variables) plays the same role as the SpuriousFeatureWrapper/SPARTAN "non-causal entity removal" test: the SPARTAN robustness metric (percentage change in prediction error when the non-causal entity is removed or altered) can be reported unchanged.

### Gaps
- CausalWorld, CoPhy, CLEVRER, CausalCircuit, Distracting Control Suite and CARL details are from prior knowledge and were not re-fetched; venue/year should be double-checked before formal citation (in particular CARL's TMLR 2023 and Distracting Control Suite's preprint-only status).
- The last ~40k characters of the survey's HTML (after Section VII-H) were not read; any additional benchmark discussion there is not covered.
- No source found that evaluates a *soft* graph prior on any of CausalWorld / CoPhy / CLEVRER / CausalCircuit / DCS / CARL with a pixel JEPA or DreamerV3.
